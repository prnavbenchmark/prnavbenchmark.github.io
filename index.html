Abstract

We introduce PRNav, a benchmark for evaluating ObjectNav under user-specified Personal-Restriction constraints in real-world indoor environments. PRNav focuses on whether embodied agents can balance goal-directed navigation with avoidance of user-specified restricted regions.

Benchmark Overview

PRNav provides task instances, restriction metadata, and evaluation metrics for measuring privacy-aware navigation behavior.

Method

We propose RAFN, a zero-shot restriction-aware frontier policy that uses target and restriction value maps to select navigation frontiers.

PRNav: Privacy-Restricted Object Navigation

Anonymous Authors

CoRL 2026

Abstract

Existing ObjectNav benchmarks primarily evaluate goal completion and path efficiency under unrestricted exploration, overlooking user-specified spatial restrictions in real-world environments. However, in practical indoor environments, successful navigation is not only about reaching the target efficiently, but also about respecting user-defined areas that the robot should avoid. To this end, we introduce Personal-Restriction-Aware Object Navigation (PRNav), a benchmark that evaluates navigation to target objects under user-specified restrictions. PRNav is built through an automatic graph-based task generation pipeline that abstracts HM3D scenes into simplified room-level scene graphs, selects restriction-relevant main paths, and generates task instances with Personal-Restriction metadata. To evaluate this setting, we introduce two metrics, Restriction Exposure (RExp) and Restriction-Aware SoftSPL (RA-SoftSPL), which measure violation severity and navigation efficiency under soft spatial constraints. We further propose Restriction-Aware Frontier Navigation (RAFN), a zero-shot baseline that ranks frontiers by balancing target utility and restriction risk using target value map and restrict value map. Experiments on PRNav show that conventional ObjectNav policies often violate Personal-Restriction regions, while RAFN provides a better trade-off between goal-directed navigation and restriction avoidance.
